# AxisMeasurement 现场参数调试与代码修改说明书

版本：第一版  
日期：2026-09-29  
适用对象：现场调试人员和维护开发人员

## 1 使用目的

本说明书回答三个问题：现场现象应先调整哪个参数，参数位于界面还是源码，修改后必须执行哪些验证。文档以程序号 61 至 999 的图形化测量链为主，也标出与旧程序共用的补偿和运动参数。

现场调试按“先界面参数、再方案参数、最后源码参数”的顺序进行。每次只改一项，记录原值、新值、试件和结果。涉及轴方向、限位、停止、脉冲当量、补偿公式或转台整周脉冲时，必须低速空载并保证物理急停可用。

## 2 参数分级

| 等级 | 调整方式 | 是否重编 | 典型内容 |
| --- | --- | --- | --- |
| A | 图形化窗口或测量方案 | 否 | 曝光、检测阈值、标定系数、ROI、三截面偏移、公差 |
| B | 修改公共源码参数 | 是 | 轴速度、加减速、到位带、光幕周期、超时、最小样本数、整周脉冲 |
| C | 修改标定公式或安全语义 | 是，并重新标定 | 轴5补偿、直径补偿、限位状态位、停止方式、圆跳动计算语义 |

优先调整 A 级。B 级必须先保存当前源码和 Release；C 级不能凭单个零件结果试凑系数。

## 4 优先通过界面调整的参数

### 4.1 曝光

图形化窗口“相机采集”区的曝光范围为 0 至 30000 微秒，界面默认值为 400。每条视觉记录保存采集时的实际曝光，自动测量按记录曝光重新设置相机。

调整方法：先固定工件、光源、镜头和 ROI，只改变曝光；观察边缘是否饱和、断裂或抖动。曝光设置失败时程序应停止，不要通过放宽边缘阈值掩盖相机问题。

源码入口：`GraphicalProgramEditor` 中的 `m_cameraExposure`；运行调用在 `makeGraphicalFreshImageCallbacks` 中。主窗口旧相机初始值位于 `AxisMeasurement.cpp` 的相机初始化代码，当前相机 0、1、2 分别为 11、400、300，但图形化记录以保存的实际曝光为准。

### 4.2 检测参数

检测参数定义在 `myCode/head/graphical_program_editor.h` 的 `GraphicalDetectionParameters`，界面位于“检测参数”页。

| 参数 | 默认值 | 允许范围 | 调大后的主要影响 |
| --- | --- | --- | --- |
| `smoothing` | 2 | 0.1 至 20 | 抑制噪声，但可能抹掉细小边缘 |
| `lowThreshold` | 20 | 0 至小于高阈值 | 减少弱边缘进入 |
| `highThreshold` | 60 | 大于低阈值至 65535 | 要求更强边缘 |
| `minLength` | 20 px | 1 至 1000000 | 过滤更多短轮廓 |
| `maxLength` | 0 | 0 至 1000000 | 0 表示图宽一半，非零时限制最长轮廓 |
| `mergeDistance` | 90 px | 0 至 1000000 | 允许距离更远的轮廓合并 |
| `cornerMaxDeviation` | 2.5 px | 0.1 至 20 | 接受偏离直线更大的倒角边 |
| `cornerMaxGap` | 20 px | 0 至 1000 | 接受交点间隙更大的两条边 |

建议顺序：先确认曝光，再调平滑和阈值，再调轮廓长度，最后才放宽倒角偏差和间隙。每次点击“应用检测参数”后重新试测，不能只看画面感觉。

### 4.3 标定和三截面

- 孔径标定：测量配置页“测孔标定”，默认 `0.00691842 mm/px`。
- 长度和圆弧标定：测量配置页“远心标定”，默认 `0.01218603 mm/px`。
- 圆柱度和跳动：下侧、上侧偏移以当前轴5中间点为基准，单位为 pulse；二者是独立正数，不要交换。
- 公称值与上下偏差：只影响判定，不应拿来修正测量值。

标定值只能由可追溯标准件和多次测量得到。若误差不是稳定比例关系，应先检查畸变、ROI、点位、焦距和补偿，不要直接改 mm/px。

## 5 补偿公式

### 5.1 轴5补偿

位置：`myCode/sourceCode/sharedFun.cpp`，函数 `axis5_compensation`。

原始换算先使用 `axis5_encodePosition × 0.0005` 得到毫米参考值，再按 0 至 320、320 至 960、960 至 1400、1400 至 1600 mm 四段多项式修正；范围外保留线性换算。

现场修正步骤：

1. 使用量块或可追溯位移标准，在全行程分段采集编码器值和真实毫米值。
2. 保留原始数据，不只记录拟合系数。
3. 分段拟合“参考毫米与真实毫米的误差”，检查分段边界是否连续。
4. 用未参与拟合的点验证最大误差和重复性。
5. 修改 `axis5_compensation` 后重编 Release，并回归跨图长度和跳动基准轴。

不要只为修正一个跨图长度结果而改变该函数，因为它同时影响旧程序、跨图长度和圆跳动轴向坐标。

### 5.2 直径补偿

位置：`myCode/sourceCode/sharedFun.cpp`，函数 `diameter_compensation`。

当前使用三次多项式修正光幕 OUT1。直径、圆柱度及旧程序共同调用该函数。现场应使用多个覆盖量程的标准件，每个标准件重复采样，拟合原始 OUT1 与标准直径的误差。修改后至少验证小、中、大三个量程点和重复性。

不要在 `captureRotationalDiameterSamples` 中另加第二套补偿，否则直径和圆柱度会产生不一致结果。

## 6 运动参数

### 6.1 自动运动速度

位置：`myCode/head/moveControl.h`。

`trapLowVelAuto` 当前轴1至轴8依次为 `{3, 3, 1, 1, 3, 1, 1, 1}`。图形化统一运行器使用此低速数组，不使用 `trapHighVelAuto`。轴5对应索引4，当前速度3；轴7对应索引6，当前速度1。

`trapAuto` 的加速度和减速度在 `myCode/sourceCode/moveControl.cpp` 构造函数中统一初始化为1，平滑时间为30。

调试规则：首次现场只允许降低速度。确认方向、限位、急停和停止距离后，才可逐步提高。速度、加速度和减速度的物理单位由控制卡配置决定，源码不能证明其现场单位。

### 6.2 到位误差带

位置：`moveControl::pBand` 和 `moveControl::pTime`。

`pBand` 当前轴1至轴8为 `{80, 80, 800, 800, 200, 800, 800, 800}` pulse。图形化运行器判定为“轴已停止，并且编码器与目标差的绝对值不超过 pBand”。轴5当前200 pulse，按基础当量约为0.1 mm；轴7当前800 pulse，但其角度意义必须以真实脉冲当量确认。

误差带调大只会更容易判定到位，不会提高机械精度。若频繁未到位，应先检查伺服、负载、机械回差、编码器和目标是否可达，不能直接无限放宽。

`pTime` 由控制卡 `GTN_SetAxisBand` 使用，当前轴5为500 ms、轴7为100 ms；图形化软件轮询还会独立检查 `pBand`。

### 6.3 停止参数

`pDecSmoothStop` 当前均为2，`pDecAbruptStop` 当前均为80。它们在 `moveControl::setStopPrm` 中写入控制卡。修改会直接影响停止距离和机械冲击，必须低速空载测量实际停距，并保留物理急停。

状态位 `0x20`、`0x40`、`0x192`、`0x200` 和 `0x400` 分别参与限位、故障、使能和运动判断。除非已核对控制卡手册和现场接线，不得修改这些掩码。

## 7 光幕和转台采样

### 7.1 光幕缓存周期

位置：`myCode/sourceCode/lsThread.cpp`，`sleepTime = 300`，单位毫秒。线程每轮连续读取 OUT1 至 OUT4，再用同一时间戳原子发布。

减小周期可增加理论样本数，但会增加 SDK 调用频率和线程负载。调整前先记录光幕实际更新频率；若设备本身只以较低频率更新，单纯减小线程周期不会增加有效新样本。

### 7.2 新鲜度和等待时间

- OUT1 单次等待超时：2500 ms。
- 缓存新鲜度上限：3000 ms。
- 采样轮询间隔：20 ms。
- 转台整周等待超时：120000 ms。

对应代码位于 `AxisMeasurement.cpp` 的 `readFreshLightCurtainOut1`、`captureRotationalDiameterSamples` 和 `captureRotationalRoundoutSamples`。程序只接受采集开始时间戳之后的新缓存值。

若设备正常但偶发超时，应先查连接、SDK阻塞和实际更新周期，再决定增加等待时间。不要通过扩大“新鲜度上限”允许复用旧样本。

### 7.3 整周脉冲和样本数

`fullRevolutionPulses = 360 × 500 = 180000`，在圆柱度和跳动采样函数中各有一处。它隐含轴7每度500 pulse。只有用现场转台铭牌、减速比、控制器电子齿轮和实测一圈共同确认后才能修改，两处必须保持一致。

圆柱度每截面至少5个新OUT1样本。圆跳动每截面至少25组同步OUT1/2/3样本，并在稳健峰谷差中从两端各剔除12个值。降低圆跳动最小样本数会使公式没有有效中间区间，禁止现场直接降低。

圆跳动截面中心当前按样本序号等角度拟合。如果实际采样时间明显不均匀或转速波动，优先改为同时记录轴7编码器角度，而不是靠增大样本数掩盖相位误差。

## 8 相机和视觉故障定位

| 现象 | 检查顺序 |
| --- | --- |
| 没有新帧 | 相机连接、连续采集是否被占用、曝光设置返回值、帧序号是否增长、2000 ms 等待超时 |
| 图像正常但无边缘 | ROI 是否覆盖目标、曝光、平滑、高低阈值、最短轮廓 |
| 边缘很多且结果跳动 | 光照固定、曝光是否饱和、提高低阈值或平滑、缩小 ROI |
| 倒角候选过多 | 缩小 ROI、降低合并距离、收紧偏差和间隙，不要直接手选后忽略复测 |
| 长度比例稳定偏差 | 重新标定 mm/px；跨图还要检查轴5补偿差 |
| 跨图长度方向相反 | 核对起点和终点记录、轴5方向与补偿，不要在结果处取绝对值掩盖方向问题 |

## 9 传感器故障定位

| 现象 | 检查顺序 |
| --- | --- |
| 直径偏差稳定 | 原始OUT1、`diameter_compensation`、标准件和温度 |
| 直径偶发旧值 | 光幕线程是否运行、时间戳是否递增、不要增大缓存新鲜度 |
| 圆柱度样本不足 | 光幕更新频率、轴7速度、缓存周期、整周实际时长 |
| 圆跳动样本不足 | OUT1/2/3是否同时有效、线程周期、轴7速度和一圈脉冲 |
| 圆跳动基准退化 | 两个基准特征是否不同、是否位于目标前、三个截面是否有轴向间距 |
| 圆跳动重复性差 | 夹持、转台跳动、同步采样、角度均匀性、基准件和机械回差 |

## 10 不应直接修改的内容

- 不修改生成后的 `program_N` JSON、清单或 SHA-256 来绕过校验，应回到测量方案重新生成。
- 不在各个测量函数中复制补偿公式，轴5和直径补偿保持单一公共入口。
- 不删除超时、取消、样本数量、有限值、退化轴线和停止失败检查。
- 不把失败结果改成0或默认合格。
- 不通过放宽 `pBand`、限位掩码或缓存新鲜度来隐藏硬件故障。
- 不同时修改速度、加速度、到位带和停止减速度，否则无法定位影响。
