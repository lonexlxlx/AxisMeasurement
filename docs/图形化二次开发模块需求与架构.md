# 图形化二次开发模块需求与架构

## 长度、直径与孔径的接入边界（2026-09-15确认）

- 后续基础测量类型明确包含长度、直径和孔径，不能用“其他测量类型”概括后遗漏。
- 直径沿用原软件光幕传感器链。源码中`lsSensorMeasure_diameter`读取光幕OUT1并执行`diameter_compensation`，点位记录保存光幕轴编码器与换算位置；图形化界面应提供传感器记录和状态，不要求用户为直径绘制图像ROI。
- 孔径沿用测孔相机链。点位记录同时包含孔轴、光幕轴、测孔相机曝光和孔序号；旧`cam1Picture_holeAlgorithm*`随程序和孔型存在不同实现、未实现占位或硬编码区域，接入前必须逐型审计，不能把一个样本函数宣称为通用孔径算法。
- 长度属于远心视觉特征关系。现有程序的单图轴向长度由指定两条拟合线的位置差乘相机标定系数；跨图长度还叠加两个拍照点位经轴补偿后的实际移动距离。画布中手绘线或拟合线的可见长度不能直接作为零件长度。
- 实施顺序为：先完成记录结构和工程保存，再分别接入直径传感器、孔径相机和远心长度；每项独立完成配置、采集/试测、单位、失效、保存及失败状态闭环。光幕、相机标定和真实轴位移只能在对应硬件环境验收。

### 接入与验证边界

- 复用现有控制卡实例，不另开控制卡连接；共享设备运动状态，新窗口独立保存所选轴并向SDK显式传递轴号，不改写旧界面的currentAxisNumber。图形化窗口使用应用模态，防止两个窗口同时交互；自动测量/回零运行期间禁止打开图形化窗口。没有迁移或启停旧轴监控线程。

## H5-E：单ROI框选倒角（2026-09-14首版接入，实图验收待完成）

- 角度记录新增“单ROI：框选相邻角 / 倒角”，默认仍为双ROI。模式通过新增/更新记录提交，单ROI清除第二ROI引用并禁用其关联入口；配置页增加滚动以容纳新增控件。
- 单ROI独立执行Canny、`lines`直线分段(5,4,2)、回归属性计算、近似共线段合并、长度筛选、Tukey逐段拟合与P90点线偏差检查。实图反馈表明`lines_circles`会把带圆滑/模糊过渡的目标边段归为曲线，导致两条长度合格轮廓只剩一条直线；因此本模式按用户原思路强制分成直线段，不再依赖`cont_approx`类型标签。共线合并使用角点间隙作为绝对断口上限、相对距离1、横向偏移为P90偏差阈值、方向差0.10 rad；不会合并夹角明显不同的两条目标边。通用“合并距离”仍仅用于原圆弧/双ROI流程。
- 新参数：90%点线偏差默认2.5 px、最大角点间隙默认20 px。拟合使用Tukey稳健法，独立质量门槛采用轮廓点偏差P90，允许最多约10%的毛刺、端部圆角或模糊过渡点，不再由单个最大偏差点否决整条边；若偏离点比例更高仍会拒绝。间隙允许两条直线跨过小圆角或模糊过渡后以延长线相交，过大会接纳不相邻干扰边。每条候选至少6个轮廓点，拟合跨度不小于最短轮廓；交点需位于ROI与图像内部并满足间隙，平行及退化边拒绝。
- 诊断分别统计点数、拟合输出、拟合跨度和最大偏差造成的排除数，用于区分边缘未找到与候选筛选过严。
- 角点交点在ROI边界内外2 px均视为框选包含，降低ROI边界取整造成的偶发拒绝；交点仍必须位于原图并满足两条线各自的角点间隙。
- 与旧软件的关系：旧`Straight_TLineFP_P`需要一条已知引导线，使用HALCON Metrology提取单线后，以`FitLineContourXld('tukey',-1,0,5,2)`拟合；旧倒角角度多为这条线相对水平或垂直方向的角度。单ROI自动寻找两条线及配对是新增能力，不能声称直接调用了旧软件的完整角度算法；这里只复用了旧软件的Tukey拟合设置，并对无引导线场景增加分段、合并和配对。
- 唯一边对自动计算较小夹角或补角；多边对只显示待选择，用户在“候选边对”中选择后采用对应真实拟合边。候选边、角点、选中索引及参数保留于内存记录；叠加为只读边缘、拟合线和角区，不新建可编辑测量特征。
- 修改ROI、重新关联、删除关联或应用参数统一清除旧值及候选；更新记录重建结果。读取记录时恢复已提交模式与参数，未提交的模式输入不影响当前试测。工程持久化仍是下一阶段。
- 实图效果尚未验证：尤其是短倒角能否被分段识别、相邻噪声边的消歧、角区贴合和重复性，需要匹配HALCON 18.11运行库与样图。较小倒角可能低于分段与图像采样能力，不承诺通过缩放画布提高原图测量精度。
- 分段直线类型依据：[HALCON 18.11 SegmentContoursXld](https://www.mvtec.com/doc/halcon/1811/en/segment_contours_xld.html)。

- 用户于2026-09-11确认：除现有双ROI角度流程外，增加单ROI框选一个角并直接测量的模式；目标为倒角斜边与相邻主体边的夹角，需覆盖尺度较小的倒角。

- 圆心-半径模式的“灵敏”反馈：当前半径等于圆心到光标的距离（边界处截断），没有额外增益。不直接乘减速系数，以免圆周脱离光标；优先尝试放大图像精细绘制，必要时另行设计可见的精调模式。

## 1. 升级目标

将现有“填写分类表单、记录设备点位、导出 Excel、运行 VBA 生成程序”的二次开发辅助模块，升级为软件内的图形化编程模块。

目标工作流：

1. 获取相机图像或打开本地图像。
2. 在图像上创建几何特征。
3. 选择需要测量的特征及测量方法。
4. 配置公称值、公差、算法和相机参数。
5. 记录或手动填写设备点位。
6. 编排测量步骤并执行完整性检查。
7. 生成兼容现有 `program_N` 体系的程序文件。

## 2. 第一版范围

### 2.1 图像来源

- 打开本地图像。
- 获取并显示相机当前图像。
- 无硬件连接时仍可使用本地图像完成编辑和生成。

### 2.2 图形工具

- 选择和移动。
- 点。
- 直线。
- 矩形 ROI。
- 圆。
- 圆弧。
- 删除。
- 撤销和重做。
- 扩大图形命中区域，使缩放状态下仍容易选中细线和轮廓。
- 支持选中图形后的平移；矩形、直线和圆弧后续支持旋转控制柄。
- 矩形提供从角点拖拽和从中心向外拖拽两种绘制方式。
- 圆在选中或绘制时显示从圆心指向圆周的半径线。

第一版暂不包含多边形 ROI。

### 2.3 优先测量功能

1. 直径。
2. 孔径。
3. 长度、角度和圆弧半径。

基础计算能力包括：

- 点坐标。
- 直线长度与角度。
- 圆心、半径与直径。
- 圆弧圆心与半径。
- 两点距离。
- 点到直线距离。
- 两直线夹角。
- 矩形 ROI 内执行指定视觉检测。

## 3. 建议界面布局

### 3.1 左侧：工具与图像源

- 打开图像。
- 获取相机图像。
- 选择、点、线、矩形、圆、圆弧工具。
- 撤销、重做和删除。

### 3.2 中央：图像画布

- 显示原始图像。
- 支持缩放和平移。
- 绘制和编辑几何特征。
- 显示特征名称、序号和选中状态。
- 图形坐标始终保存为原始图像坐标，不受界面缩放影响。

### 3.3 右侧：属性与测量配置

- 当前特征类型、名称和几何参数。
- 测量类型。
- 公称值、上偏差和下偏差。
- 相机、曝光和算法参数。
- 设备轴点位；无硬件时允许手动输入或保持未记录状态。

### 3.4 底部：流程编排

- 按顺序显示测量步骤。
- 支持新增、删除、复制及上下移动。
- 每一步引用一个或多个图形特征。
- 生成前显示缺失参数和无效引用。

## 4. 核心数据模型

### 4.1 图形特征 `GraphicFeature`

- 唯一标识。
- 名称与显示序号。
- 类型：点、直线、矩形、圆或圆弧。
- 原始图像坐标下的几何参数。
- 显示颜色、可见状态和锁定状态。

### 4.2 测量定义 `MeasurementDefinition`

- 唯一标识。
- 测量类型：直径、孔径、长度、角度或圆弧半径等。
- 引用的图形特征标识。
- 公称值与公差。
- 算法和相机参数。

### 4.3 设备点位 `DevicePosition`

- 各运动轴编码器位置和实际位置。
- 相机或传感器选择。
- 曝光等采集参数。
- 点位来源：硬件记录、手动输入或未设置。
- 设备未连接时禁止直接读取硬件对象，避免程序崩溃。

### 4.4 流程步骤 `ProgramStep`

- 执行顺序。
- 动作类型：移动、采图、测量、计算或保存。
- 引用的测量定义和设备点位。
- 启用状态与备注。

### 4.5 工程文件 `GraphicalProgramDocument`

- 文件版本。
- 程序编号及零件信息。
- 图像引用或预览图。
- 全部图形特征、测量定义、设备点位和流程步骤。
- 使用 JSON 保存，以便重新打开和继续编辑。

## 5. 兼容策略

第一阶段不立即移除现有 Excel/VBA 生成器：

- 新图形化模块使用统一数据模型保存工程。
- 生成端先将统一数据转换为现有生成器能够表达的直径、孔径、长度、角度和圆弧半径数据。
- 保留 `program0107.xlsm` 作为兼容生成出口和结果对照基准。
- 图形化生成稳定后，再评估用 C++ 模板生成器完全替代 Excel/VBA。

## 6. 验收约束

- 未连接硬件时，打开图像、绘图、编辑、保存和生成不得崩溃。
- 图像缩放后，保存的特征坐标仍对应原始图像像素。
- 工程保存后重新打开，图形、参数和步骤顺序必须一致。
- 生成文件必须使用 UTF-8，并能够被 VS2019、Qt 5.14.2、Release x64 工程编译。
- 新模块不得破坏现有登录、主窗口、测量程序及旧生成器。

## 7. 交互问题与处理决定

### UI-GRAPH-001 初始特征提示被截断

- 现象：左侧“图形特征”区域的初始说明需要拖宽后才能完整显示。
- 原因：初始提示文字过长，左侧区域初始宽度不足。
- 处理：缩短空状态文字，并适当提高左侧区域的最小宽度。

### UI-GRAPH-002 单击产生零尺寸图形

- 现象：选择矩形或圆后仅轻点画布，仍会在特征列表中生成记录。
- 原因：原判断使用包含画笔宽度的外接矩形；零尺寸几何也可能因画笔宽度通过检查。
- 处理：改用屏幕拖拽距离判断；小于系统最小拖拽距离时取消创建。

### UI-GRAPH-003 右键菜单和双向选择

- 需求：画布图形和左侧特征记录均支持右键操作；选择任一侧时另一侧同步选择并高亮。
- 已实现：画布与列表使用统一特征标识，支持双向选择、高亮、定位和删除；缩放、平移后联动正常。

### UI-GRAPH-004 图形移动

- 需求：选中的点、线、矩形、圆和圆弧可以移动。
- 约束：移动后必须更新原始图像坐标、限制在图像边界内，并同步属性和后续测量引用。
- 已实现：点、直线、矩形、圆和圆弧均可移动并受图像边界约束，移动后发出坐标更新通知。

### UI-GRAPH-005 圆形反向拖动锚点漂移

- 现象：绘制圆形时，起始点在部分拖动方向上看起来会移动。
- 原因：预览矩形先归一化再改为正方形，横纵拖动距离不一致时破坏了原始角点锚定关系。
- 处理：根据拖动方向计算正方形左上角，始终保持按下点为固定角点。

### UI-GRAPH-006 图形移动与画布平移手势

- 图形移动：选择模式下使用左键拖动图形。
- 画布平移：保留中键拖动，并已增加“空格键加左键拖动”。
- 不默认使用“空白处左键拖动画布”，因为它会与框选多个特征及误触防护冲突。
- 右键保留给上下文菜单，不用于拖动画布。

### UI-GRAPH-007 圆和矩形的绘制方式

- 现象：圆使用外接正方形预览，最终才显示为圆，且半径辅助线固定朝右，用户难以判断最终结果。
- 原因：预览图元与最终图元类型不一致；绘制方式只有外接框角点拖拽一种。
- 处理：圆预览改为真实圆形，绘制中的半径线跟随光标方向；圆提供“外接框”和“圆心-半径”两种模式，矩形提供“角点-角点”和“中心向外”两种模式。
- 默认值：继续使用圆的“外接框”和矩形的“角点-角点”，避免无提示改变既有操作习惯。
- 验证：选择及绘图模式下空格加左键均只平移，不误移动或创建图形；切换窗口后无残留平移状态。

### UI-GRAPH-007 三点圆弧绘制

- 定义：依次点击起点、弧上点和终点，以三点确定圆弧。
- 退化处理：三点过近或近似共线时拒绝生成并允许重新选择终点；按 `Esc` 可取消未完成圆弧。
- 验证：向上、向下弯曲方向均正确，生成圆弧经过三个输入点；选择、移动、边界约束、列表联动、删除、缩放和平移均正常。
