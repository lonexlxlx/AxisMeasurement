# AxisMeasurement 面板功能测试指南

## 单ROI倒角首版验收（2026-09-14，待实图执行）

1. 打开有清晰倒角的原图，画一个包含倒角斜边、目标相邻主体边和角点的矩形或圆ROI。测量类型选“角度”，角度选取选“单ROI：框选相邻角 / 倒角”，填写特征号，新增记录；必要时点“选择/重选包含相邻角的ROI”再选框。
2. 在检测参数页确认最短轮廓是否小于倒角边长（原图像素）。默认20 px可能排除短边，可先尝试6–10 px；平滑过强可适当降低。90%点线偏差默认2.5 px，允许少量毛刺或圆角过渡点；角点间隙默认20 px，以允许过渡两侧的拟合线延长相交。输入后点击“应用检测参数”，再试测。上述数值是调试起点，不是精度保证；单ROI不使用合并距离。
3. 唯一相邻边对应直接显示角度、绿色原始边缘及橙色拟合线/角区。检查选中的确为倒角斜边与目标主体边。切换较大补角需“更新选中记录”并重新试测；较小角与补角之和应为180°。
4. 将ROI扩大到包含多个角：应显示待选择且无数值；在测量配置“候选边对”逐项选择并观察叠加，确认目标后采用。选择真实算法候选不能拖动拟合线；边对唯一不代表一定选中了所需物理特征。
5. 空白、仅一条边、平行边、交点远离两边端点、圆弧及干扰噪声分别试测：无合理边对时不得输出0或沿用旧值。拍下完整诊断；大角点间隙可能接纳非目标边，不应盲目增大。
6. 移动/缩放/旋转ROI、应用参数、重关联、删除ROI、更新角度模式后检查角度与候选清空；切换记录应恢复各自已提交模式和参数。未提交的模式输入不改变已保存记录。单ROI时ROI2入口禁用，提交双ROI后恢复。
7. 回归原圆弧和双ROI角度；记录样图、原图像素尺寸、参数、目标边、诊断和测量重复值。仍显示“未判定”，本阶段不进行标定精度或真实运动验收。

8. 稳定性复测时固定同一张静态原图、同一ROI和同一组已应用参数，连续试测至少10次，结果应每次一致；随后只分别向四个方向移动ROI少量像素，确认只要仍包含角点和两段足够长的直线就能输出同一目标边对。诊断应显示“直线分段→共线合并→长度筛选→有效直线→相邻边对”。若固定输入仍时成时败，应按程序状态问题处理；若只在移动ROI后失败，依据各阶段数量判断边缘截断、长度不足、偏差过大或交点间隙不足。

本机离线测试不加载HALCON算法，也不连接设备；实图验收需匹配工程的HALCON 18.11运行库与有效许可。

若旧版本显示“单ROI直线拟合：HALCON 2: Illegal operation on tuple”，这是`cont_approx`属性读取类型错误，不是通过调整阈值可解决的无边缘问题。新版单ROI已改为直接按直线段分割，不再读取该属性；仍保留拟合输出元组保护。

1. 设备打开 + 回零完成。

   - "测量程序状态"文字逐步变化（走到哪一步显示哪一步）；
   - 中间图像区显示采图；
   - 过程中弹确认对话框时，点"继续测量"走下一步，点"检测取消"中止。
4. 测量跑完 → 预期：
   - 结果表逐行填入：数值列等宽粗体，**OK 行绿字、NG 行红字浅红底、临界行橙字浅橙底**（一眼可辨）；
   - 测量统计的检测零件数 +1、OK/NG 计数、良品率刷新；
   - "保存测量结果"解除灰色，点击后数据入库 + 导出 xlsx（`measureData\Report\` 下）。
5. 中途点一次"紧急停止" → 预期：全窗口闪红、机构停、程序状态提示中止。

入口：二次开发辅助 → 打开图形化编程。先做以下离线检查，再安排现场运动验证。

| 离线操作 | 预期 |
|---|---|
| 打开图形化窗口 | 左侧上方轴控制、下方图形列表；中央画布；右侧属性/配置/点位；底部测量流程 |
| 未连接设备 | 状态为未连接/未采集；不能使能或移动轴，不显示0冒充真实位置 |
| 拖动左侧上下分隔条和三栏分隔条 | 画布与列表大小可调整；控制区内容不足时可滚动，顶部停止/全部轴急停始终可见 |
| 打开本地图像并操作ROI、记录 | 原编辑流程仍可操作；本轮没有增加相机采图或设备点位保存 |
| 尝试切换到主窗口操作 | 图形化窗口打开期间，其他应用窗口的交互被限制；关闭编辑器后恢复 |
| 关闭再打开图形化窗口 | 布局与控制接口仍正常，没有重复面板 |

现场验证须先确认物理急停、限位和轴周边安全，按现有规程空载、低速逐轴进行。默认速度1 pulse/ms并非已验证安全值，应按现场设备选择；新面板目标位置是绝对pulse坐标，不是增量距离。

1. 在主窗口打开设备，再进入图形化窗口；确认1/2/5/6/7轴名称、规划与编码器位置、使能、运动、报警和限位状态与设备对应。
2. Jog分别短按正负方向，核对方向；释放后停止。切换到其他应用时停止，不应在恢复窗口后自动重启；移动中轴号和参数不可修改。
3. “绝对点位”填写已确认的小范围目标，点击移动并核对到位。加减速沿用原轴参数；不要把目标0误认为不移动。
4. 分别验证“停止当前轴”和“全部轴急停”。软件急停使用控制卡急停减速度并保留伺服使能；垂直轴保持、减速度和停距必须现场确认。
5. 移动中关闭窗口或点击试测，应先请求停止；未确认停止时拒绝关闭/试测。模拟通信异常需先用物理急停保证设备安全，确认失败提示和界面响应，不因软件按钮发出命令便认定已停。
6. 自动测量/回零运行期间不能打开图形化窗口；旧窗口运动未结束时，新移动入口应拒绝命令。全部结束后关闭图形化窗口，回归旧手动控制页。

自动离线回归：主工程Release x64编译完成后运行 `tests/run_graphical_axis_panel_test.ps1`。测试后端不连接硬件，覆盖Jog释放、失焦、固定轴停止、启动响应丢失、停止失败关闭保护及常驻停止栏；不验证真实SDK通信、运动精度或检测算法。
