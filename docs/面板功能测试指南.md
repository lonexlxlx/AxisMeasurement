# AxisMeasurement 面板功能测试指南

> 面向不熟悉本软件的测试人员。按"无硬件 → 有硬件 → 自动测量"三个阶段推进，每个面板给出操作步骤、测试数据和**预期结果**（预期结果不对 = 有问题，记下来）。
>
> 适用于 P2 布局重构后的版本（面板收纳在页签里、左右分栏可拖动）。

---

## 第 0 步：测试前提（必读）

1. **程序必须能启动**：需要 `x64\Release\` 下有全部 DLL（大恒 SDK 已装；HALCON 18.11 的 `halconcpp.dll` 还没装的话程序起不来，先装）。
2. **登录**：用户名 `XJTU`，密码 `121314`。**输完每一栏按一下回车**再点登录（输入框靠回车提交，直接点按钮可能读到空值）。
3. **一个重要概念**：这套软件的绝大部分功能都有"设备门槛"——没连相机/运动控制卡/光幕时，"打开设备"会失败，**手动控制页、程序选择、开始测量全都保持灰色**。这不是 bug，是设计如此。所以测试分两阶段。

## 第二阶段：连上硬件后测的

> 硬件=大恒相机×3 + 固高运动控制卡 + LS9 光幕 + 顶尖/转台机构。连好后从这继续。

### 2.1 打开设备（一切的前提）

1. 点"打开设备" → 预期：状态栏变 **●绿 设备已打开**，"程序"下拉框、"设备回零"、"开始测量"全部解除灰色。
2. 点"设备回零" → 预期：各轴回原点，轴状态指示灯变化，期间按钮不可重复点。

### 2.2 手动控制页（菜单 → 测量模式选择 → 手动控制）

设备已打开才能进。进去后重点测 P2 收纳的 5 个页签 + 轴监控：

**轴监控（常驻左侧）**
| 检查点 | 预期 |
|---|---|
| 8 个指示灯 | 使能/负限位/驱动报警/正限位/IO急停/跟随误差/运动状态等，绿色=正常，异常变红 |
| 实时位置 | 数值随轴运动刷新 |

**运动轴设置页签**
| 操作 | 预期 |
|---|---|
| 轴号下拉换轴 | 下面的点位/Jog 参数跟着切换到该轴的参数 |
| "伺服使能"→"关闭伺服" | 指示灯切换，轴上电/掉电 |
| "位置清零" | 当前轴位置显示归 0 |
| "紧急停止" | 轴停 + **P2 闪红边框** |
| "一键回原点" | 轴回零 |

**Jog运动页签（按住走、松手停）**
测试数据建议从小值开始：
| 参数 | 建议测试值 | 说明 |
|---|---|---|
| 速度 | 50 | 脉冲/ms，先慢 |
| 加速度/减速度 | 0.5 | 脉冲/ms² |
| 平滑系数 | 0.5 | 范围 0~1 |
| 正向/负向 | 按住看轴动 | 伺服使能后才有反应 |

**点位运动页签（走固定步长）**
| 参数 | 建议测试值 |
|---|---|
| 步长 | 1000（脉冲） |
| 速度 | 20 |
| 加/减速度 | 0.5 |
| 平滑时间 | 10（范围 0~50） |
| 点"启动运动" | 轴走一个步长后停，轴监控位置变化对应 |

**相机采集页签**
| 参数 | 建议测试值 |
|---|---|
| 相机选择 | 3 台轮换测 |
| 曝光时间 | 400（μs，默认值，范围 0~30000） |
| 增益 | 0（范围 0~24dB） |
| 开始采集 | 右侧"相机图像"区出实时图 |
| 结束采集 → 图像保存 | measureData 下出现 bmp |

**光幕传感器页签**
| 检查点 | 预期 |
|---|---|
| OUT1~4 数值 | 20pt 绿色等宽大数字，挡光幕后数值变化 |
| 补偿前数值 | 琥珀色大数字 |
| 跳动数据采集 | 光幕下移采集一圈数据后回到原位（动作流程完整） |

### 2.3 顶尖/旋转/光幕位置页签（自动页左下，设备打开后启用）

| 操作 | 预期 |
|---|---|
| 顶尖上移/下移 | 顶尖机构动作（注意工位安全！） |
| 转台慢转/快转 | 转台旋转，快转速度明显更快 |
| 光幕上移/下移 | 光幕传感器支架动作 |

## 第三阶段：自动测量全流程

1. 设备打开 + 回零完成。
2. "程序"下拉选一个（建议先选 `螺纹教学` 或 `1_WZ10451080-370`）→ 预期：右侧"零件装夹方式"显示对应图号。
3. 点"开始测量" → 预期：
   - **进度条平滑增长**（P2：OutCubic 动画，不是跳变）；
   - "测量程序状态"文字逐步变化（走到哪一步显示哪一步）；
   - 中间图像区显示采图；
   - 过程中弹确认对话框时，点"继续测量"走下一步，点"检测取消"中止。
4. 测量跑完 → 预期：
   - 结果表逐行填入：数值列等宽粗体，**OK 行绿字、NG 行红字浅红底、临界行橙字浅橙底**（一眼可辨）；
   - 测量统计的检测零件数 +1、OK/NG 计数、良品率刷新；
   - "保存测量结果"解除灰色，点击后数据入库 + 导出 xlsx（`measureData\Report\` 下）。
5. 中途点一次"紧急停止" → 预期：全窗口闪红、机构停、程序状态提示中止。

## 已知坑（测到这些不算新 bug）

| 现象 | 原因 |
|---|---|
| 无硬件点"手动控制"菜单没反应 | 代码要求设备全部打开才允许进手动页 |
| 无硬件"打开设备"报错、按钮全灰 | 预期行为 |
