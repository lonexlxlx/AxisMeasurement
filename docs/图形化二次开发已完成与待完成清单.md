## 当前明确不进入图形化流程

- 粗糙度继续使用原主软件流程，图形化编辑器不提供粗糙度测量、相机2或轴1入口。
- 螺纹尚未成为正式测量类型，离线试验通过前不加入现场操作界面。

## 下一步顺序

1. 验证配方参考图的“非实时”标识，并建立独立的实时测量帧入口。
2. 支持直径、圆柱度和圆跳动的无图像配方。
3. 在无硬件环境完成运行帧、记录隔离和失败语义测试。
4. 有硬件后优先验证真实相机、轴控制、光幕及圆柱度/圆跳动采样。
5. 测量类型稳定后接入程序生成和自动测量。
